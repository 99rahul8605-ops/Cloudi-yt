# HOW TO GENERATE THIS FILE (takes ~2 minutes):
#
#  1. Install the browser extension:
#       Chrome  → "Get cookies.txt LOCALLY"
#       Firefox → "cookies.txt" by Lennon Hill
#
#  2. Open https://www.youtube.com in your browser and LOG IN to your
#     Google account (a free account is fine).
#
#  3. Click the extension icon → make sure you are on youtube.com
#     → click "Export" → save the file as  cookies.txt
#
#  4. Replace THIS file with the exported one.
#     Keep it next to bot.py / Dockerfile.
#
#  5. Rebuild & redeploy.
#
# WHY THIS IS NEEDED:
#   YouTube detects server IPs and returns "Sign in to confirm you're not a
#   bot." Providing real browser cookies from a logged-in session tells YouTube
#   the request is human-originated and bypasses the check.
#
# SECURITY NOTE:
#   These cookies grant access to your Google account. Use a dedicated Google
#   account for the bot, not your personal one.
